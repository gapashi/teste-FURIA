# 💬 Challenge #1 - Experiência Conversacional FURIA

Este é um projeto web completo que simula uma aplicação social com funcionalidades de login, cadastro, perfil, feed de atualizações e sistema de chat em grupo. Desenvolvido utilizando **HTML5**, **CSS3**, **JavaScript puro** e **Bootstrap 5** para responsividade.

## 📌 Funcionalidades

- ✅ **Landing Page** com apresentação do sistema
- ✅ **Tela de Login e Cadastro**
- ✅ **Tela Inicial (Feed)** com posts fictícios
- ✅ **Tela de Perfil do Usuário**
- ✅ **Seleção de Grupos de Chat**
- ✅ **Tela de Chat em tempo real (frontend apenas)**

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
